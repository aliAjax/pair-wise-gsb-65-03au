# 航空温控货物运输放行与温度偏差调查平台

基于React、Ant Design、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。无需后端，浏览器持久化演示数据。

## 功能

- 温控运输任务列表、关键词和状态筛选。
- 航段时间轴、温度曲线缩放、原始时间点定位与超限标记。
- 温度曲线、设备报告、包装确认和交接签字证据的版本管理。
- 温度超限自动/人工偏差、原因调查、影响评估和放行复核。
- 多角色签收、未核验证据与未关闭偏差放行拦截、完整报告导出。
- **货站排程（`/scheduler`）**：运输任务 → 航段 → 温控箱 → 预冷位 → 干冰批次一体化排程。
  - 按航段温区（冷藏/控温/深冷）与准备时长预留冷位，按航段飞行时长冻结干冰量；
  - 预冷位容量或干冰不足自动排队，逐票列出“预冷位不足/干冰不足/温控箱冲突”缺口；
  - 两名值班员同时提交按指纹（任务+航段+设备报告版本）幂等处理，重复操作不重复占冷位、不重复扣干冰；
  - 写入失败时内存不落变更，从最后完整排程重试一次（页内“模拟下次写入失败”可演示）；
  - 设备报告更新后，未开始补给的安排失效并重算，已补给/已完成的安排保留原批次与耗量；
  - 任务列表、任务详情与审计轨迹共享同一占用、批次余量与阻断原因。
