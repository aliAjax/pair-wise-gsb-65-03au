# 航空温控货物运输放行与温度偏差调查平台

基于React、Ant Design、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。无需后端，浏览器持久化演示数据。

## 功能

- 温控运输任务列表、关键词和状态筛选。
- 货站预冷位与干冰批次统一排程：运输任务→航段→温控箱→预冷位/干冰批次，按航段温区与准备时长预留位次、按票冻结干冰，容量不足排队并列明冷位（分钟）与干冰（kg）缺口，释放后按 FIFO 补位。
- 幂等提交：同一任务+航段+设备报告版本的重复操作返回同一占用，不重复扣减；写入失败只暂存意图，从最后完整排程重试。
- 设备报告更新：未开始（已排程/排队中）的安排失效并全量重算，已预冷/已补给的安排保留原批次与实际耗量。
- 任务列表、任务详情「冷链准备」与审计轨迹显示同一位次占用、批次余量、冻结/实耗与阻断原因。
- 航段时间轴、温度曲线缩放、原始时间点定位与超限标记。
- 温度曲线、设备报告、包装确认和交接签字证据的版本管理。
- 温度超限自动/人工偏差、原因调查、影响评估和放行复核。
- 多角色签收、未核验证据与未关闭偏差放行拦截、完整报告导出。

排程演示：`预冷与干冰排程` 页可切换值班员、全量排程、模拟下一次写入失败并从最后完整排程重试、对任意任务模拟设备报告更新（延误10小时，观察排队票 FIFO 补位与干冰重新冻结）。排程基准时刻固定为 `2026-10-01T12:00:00`，避免真实时钟导致演示占用漂移。

端口为`18465`。

```bash
npm install
npm run build
npm run dev
```
